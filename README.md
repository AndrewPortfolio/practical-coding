## Networking Essentials 
### Three that Matter in sys design 
1. Network Layer (3): Handles IP routing and addressing
2. Transport Layer (4): TCP, UDP, and QUIC
3. Application Layer (7):
    - HTTP/HTTPS
    - REST
    - GraphQL
    - gRPC
    - Server-Sent Events (SSE)
    - WebSockets
    - WebRTC
